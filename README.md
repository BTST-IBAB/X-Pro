# X-Pro

**X-Pro** is a web-based computational tool for structural analysis of point mutations in proteins. It identifies potential rotameric configurations, detects interaction gains and losses at the mutation site, and integrates multiple stability predictors — all through a streamlined web interface.

**Live server:** [https://bts.ibab.ac.in/X-Pro.php](https://bts.ibab.ac.in/X-Pro.php)

---

## Overview

Point mutations in proteins can alter residue geometry, disrupt hydrogen bonds, eliminate hydrophobic contacts, and affect overall stability. X-Pro automates this structural investigation by:

- Generating the mutant structure using **PyMOL** (mutagenesis wizard) or **Modeller** (recommended)
- Identifying all low-energy rotamers for the mutant residue
- Running **LigPlot+** on both wild-type and mutant structures to map interaction networks
- Comparing pre- and post-mutation interactions (hydrogen bonds, non-bonded contacts)
- Querying external stability predictors: **FoldX**, **DynaMut2**, **DUET**, **mCSM**, **SDM**, and **HOPE**
- Presenting results as tables, diagrams, and downloadable structure files

---

## Features

| Feature | Details |
|---|---|
| Structure input | PDB ID (auto-fetch from RCSB) or direct `.pdb` / `.cif` file upload |
| Mutagenesis engines | PyMOL mutagenesis wizard · Modeller comparative modelling |
| Rotamer analysis | All low-energy rotamers enumerated and listed |
| Interaction analysis | LigPlot+ for pre/post-mutation hydrogen bonds and hydrophobic contacts |
| Stability prediction | FoldX · DynaMut2 · DUET · mCSM · SDM · HOPE |
| Visualisation | PyMOL-rendered PNG images of wild-type and mutant structures |
| Output formats | Tabular interaction summary · downloadable mutant PDB · PNG images |
| Web interface | PHP + Bootstrap 4 — no client-side installation required |

## Workflow

### Step 1 — Provide the protein structure

The homepage presents two panels simultaneously: **Step 1** (structure input) and **Step 2** (mutation parameters, initially inactive).

Enter a **PDB ID** to auto-fetch the structure from the RCSB Protein Data Bank, or click **"Click to Upload .pdb/.cif File"** to upload a local structure. Then click **"Validate and prepare input"**.

Use **"Run Example"** to instantly load a pre-computed result, or **"Reset"** to clear all fields.

![X-Pro homepage](img/X-Pro_help/01_homepage.png)

---

### Step 1 — PDB ID entered

Type the 4-character PDB accession code into the PDB ID field. The tool will download and prepare the structure upon validation.

![PDB ID entered](img/X-Pro_help/02_pdbid_entered.png)

---

### Step 2 — Mutation parameters become available

After validation, **Step 2** is populated automatically. The **Chain ID** and **Residue Number** dropdowns are filled with all chains and residues present in the structure. The **Wild-type Residue** field is auto-filled based on your residue selection.

![Step 2 populated](img/X-Pro_help/03_step2_populated.png)

---

### Step 2 — Select all mutation parameters

Choose:
- **Chain ID** — the protein chain containing the residue of interest
- **Residue Number** — the position to mutate (residue name shown automatically)
- **Mutation** — the target amino acid (all 20 standard amino acids available)
- **Mutagenesis Method** — PyMOL or Modeller *(Modeller is recommended)*

Then click **"Analyze"** to run the full analysis.

![Mutation parameters selected](img/X-Pro_help/04_mutation_selected.png)

---

### Result — Mutation summary

The result page opens with a **Summary** table listing:
- PDB ID
- Chain ID
- Residue Number
- Mutation applied
- Number of possible rotamers found after mutation (generated by PyMOL)

Below the summary, **Before Mutation** and **After Mutation** labels mark the PyMOL structural images.

![Result summary](img/X-Pro_help/05_result_summary.png)

---

### Result — PyMOL structural comparison

Side-by-side **PyMOL-rendered images** show the three-dimensional residue environment at the mutation site before and after substitution. Backbone and side-chain conformations of neighbouring residues are visible. Below the structures, LigPlot+ diagrams begin.

![PyMOL structural comparison](img/X-Pro_help/06_pymol_structures.png)

---

### Result — LigPlot+ interaction diagrams & Interactions Gained/Lost

**LigPlot+** generates 2D interaction diagrams for both the wild-type and mutant structures, highlighting:
- Hydrogen bonds (solid lines with distances)
- Non-ligand bonds
- Hydrophobic contacts (spoked arcs)

Immediately below, two tables list **Interactions Gained** (new contacts formed in the mutant) and **Interactions Lost** (contacts present in wild-type but absent in mutant), with counts for hydrogen bonds (M-M, S-S, M-S) and non-bonded contacts.

![LigPlot diagrams and interaction tables](img/X-Pro_help/07_ligplot_diagrams.png)

---

### Result — Full interaction summary & downloads

The complete interaction comparison table shows every interacting residue pair with bond counts across both the wild-type and mutant, allowing direct quantitative comparison.

At the bottom, three action buttons are available:
- **Mutated PDB** — download the mutant protein structure as a `.pdb` file
- **Interaction Summary** — download the full interaction table as CSV
- **Reset** — clear the session and start a new analysis

![Interaction summary and downloads](img/X-Pro_help/08_interactions_table.png)

## Installation

### Requirements

| Component | Version |
|---|---|
| Apache | 2.4+ |
| PHP | 7.4+ |
| Python | 3.8+ |
| Java | 11+ (for LigPlot+) |
| MySQL / MariaDB | 5.7+ |
| PyMOL (open-source) | 2.x |
| Modeller *(optional)* | 10.x |

### 1. Clone the repository

```bash
git clone https://github.com/BTST-IBAB/X-Pro.git
cd X-Pro
```

### 2. Deploy to web root

```bash
sudo cp -r . /var/www/html/
```

### 3. Configure the database

Edit `connect.php` and fill in your MySQL credentials:

```php
$servername = "localhost";
$username   = "your_db_user";
$password   = "your_db_password";
$dbname     = "your_db_name";
```

### 4. Install Python dependencies

```bash
pip3 install biopython requests pymol-open-source
# If using Modeller:
# Follow https://salilab.org/modeller/download_installation.html
```

### 5. Download external binaries

The following large binaries must be downloaded separately and placed at the paths below:

| Binary | Path | Source |
|---|---|---|
| FoldX | `pointMutationScript/foldx` | [https://foldxsuite.crg.eu](https://foldxsuite.crg.eu) |
| LigPlot+ `components.cif` | `pointMutationScript/LigPlus/components.cif` | [https://www.ebi.ac.uk/thornton-srv/software/LigPlus](https://www.ebi.ac.uk/thornton-srv/software/LigPlus) |

### 6. Set permissions

```bash
sudo chmod -R 755 /var/www/html/pointMutationScript/
mkdir -p /var/www/html/fileUpload
sudo chmod 777 /var/www/html/fileUpload/
```

## Example Analysis

The built-in example (click **Run Example** on the homepage) uses PDB structure **1BBT**, Chain **1**, Residue **60** (Threonine → Methionine).

- **12 rotamers** are identified for methionine at position 60
- **Interactions gained:** GLY 63 forms a new non-bonded contact with THR 60
- **Interactions lost:** LEU 61 loses 8 non-bonded contacts with MET 60

## Output Files

| File | Description |
|---|---|
| `not_mutated.png` | PyMOL image of the wild-type structure |
| `mutated.png` | PyMOL image of the mutant structure |
| `mutated.pdb` | Mutant protein structure (downloadable via "Mutated PDB" button) |
| `*_ligplot.hhb` | LigPlot+ hydrogen bond table (wild-type) |
| `*_ligplot.nnb` | LigPlot+ non-bonded contact table (wild-type) |
| `altered_ligplot.hhb` | LigPlot+ hydrogen bond table (mutant) |
| `altered_ligplot.nnb` | LigPlot+ non-bonded contact table (mutant) |
| `altered_ligplot.png` | LigPlot+ interaction diagram (mutant) |
| `altered_ligplot.csv` | Interaction summary as CSV (downloadable via "Interaction Summary" button) |
